# Synapse

Synapse is a frontend-only neural network visualization and training application built with React 19, TypeScript, Vite, and Tailwind CSS. It includes a real machine learning engine that runs entirely in the browser — no backend required.

## Features

- **Neural Network Builder**: Configure layers, activations, weight initialization, and architecture visually
- **Real Training Engine**: Backpropagation, gradient descent, momentum, and Adam optimizers running in the browser
- **Dataset Lab**: Generate synthetic datasets (XOR, regression, classification, clusters, circles, moons, spiral) with train/validation splits
- **Training Lab**: Train networks with live loss curves, epoch tracking, and metric visualization
- **Neural Observatory**: Visualize layer activations and signal propagation through the network
- **Weight Explorer**: Inspect weight matrices and bias distributions per layer
- **Digit Recognition**: Draw digits on a canvas and predict them with a locally trained network
- **Decision Boundary**: Visualize 2D classification boundaries generated by trained networks
- **Model Comparison**: Train multiple models side by side and compare loss curves and accuracy
- **Experiments**: Save, load, duplicate, and delete experiments with IndexedDB persistence
- **Settings**: Configure appearance, animation, visualization, and training defaults with import/export
- **Command Palette**: Quick navigation with Ctrl+K or /

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Zustand (state management)
- Framer Motion (animations)
- Lucide React (icons)
- Recharts (charts)
- Vitest + jsdom (testing)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build

# Run linter
npm run lint
```

## Project Structure

```
src/
├── app/              # Router, navigation, context
├── components/       # Shared UI components (button, panel, command palette)
│   ├── ui/           # Primitive UI components
│   ├── layout/       # Layout components (sidebar, topbar, workspace)
│   └── command-palette/ # Command palette
├── features/         # Feature pages (dashboard, training, settings, etc.)
├── hooks/            # Custom React hooks
├── lib/              # Core libraries (ML engine, datasets, storage, utils)
│   ├── ml/           # Machine learning engine (matrix, network, training, etc.)
│   ├── datasets/     # Dataset generators and validation
│   ├── storage/      # IndexedDB persistence layer
│   └── math/         # Matrix operations
└── stores/           # Zustand state stores
```

## Testing
